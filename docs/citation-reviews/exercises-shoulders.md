## Lateral raise

**[1] Larsen S, Wolf M, Schoenfeld BJ, Sandberg NØ, Fredriksen AB, Kristiansen BS, van den Tillaar R, Swinton PA, Falch HN. Front Physiol 2025;16:1611468.** https://doi.org/10.3389/fphys.2025.1611468

Read: full text on frontiersin.org. Funding: Jaquish Biomedical. Conflicts: B. J. Schoenfeld formerly served on
the scientific advisory board of Tonal Corporation; the other authors declared none. The page states both,
without characterising either company, since the paper does not.

| Claim | Where |

| ★ Within-person: each arm randomly assigned dumbbell or cable | Methods ("Participants' upper limbs were randomly assigned to one of two exercise conditions") |
| ★ Eight weeks, twice weekly; 4 sets per arm in week 1, then 5; 12–16 reps to failure (unable to reach 90°) | Methods |
| ★ Side-deltoid thickness: cable +4.6% / +3.3%, dumbbell +3.9% / +3.4% (two sites) | Table 2 |
| Analysis favoured no difference between tools | Results (Bayes factors 0.27 and 0.22; multivariate BF < 0.01) |
| No control group; typical ultrasound error (~0.4 mm) large relative to changes (0.5–1 mm) | Limitations |
| Cable pulley level with the hand; elbow straight; raise to 90°; ~1 s up, ~1 s down (how-to) | Methods |

Doubt: the credible intervals as printed did not appear to match the point estimates (e.g. "0.72 to 0.22 mm"
around −0.25 mm). No interval is used on the page; the conclusion rests on the Bayes factors and Table 2.
